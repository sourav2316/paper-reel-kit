# Background music folder

Put 3–6 royalty-free tracks (.mp3) here. **Every video automatically gets one of them** at **6.5% volume**,
with a 1 s fade-in and a 1.5 s fade-out. The same project always keeps the same track.

- Choose a specific track for a video: `"music": "/music/curious-pizzicato.mp3"` in storyboard.json
- Change the level for one video: `"musicVolume": 0.07`
- No music for a video: `"music": false`

## Where to get music that's safe for YouTube / Instagram
1. **YouTube Audio Library** (studio.youtube.com → Audio Library). Safest for YouTube. Filter by
   "Attribution not required". Moods that suit this style: *Funny*, *Bright*, *Calm*. Genres: *Ambient*, *Cinematic*, *Children's*.
2. **Pixabay Music** (pixabay.com/music). Free, no attribution needed. Search: "quirky", "curious", "pizzicato",
   "lofi documentary", "ukulele". Occasionally a Pixabay track gets a Content ID claim; if that happens, dispute it with the
   Pixabay license link or switch tracks.
3. **Uppbeat** (uppbeat.io) free plan. Good "quirky explainer" tracks, but you must paste their credit line in the description.

Avoid: Bollywood/film songs, trending Instagram audio, and "no copyright" uploads by random YouTube channels. These get
claimed or muted.

## What fits this style
Light, curious, mostly instrumental, steady tempo, no vocals:
- pizzicato strings / plucky "curious" explainer music
- soft lo-fi with a light beat
- ukulele / glockenspiel playful
- for serious topics (health, money stress): soft piano + ambient pads

Name files in kebab-case, e.g. `curious-pizzicato.mp3`, `lofi-documentary.mp3`.
